# DX7 / Dexed Presets

Yamaha DX7 patch banks in SysEx (`.syx`) format.

The banks with **Aquanode** in front are my own patches, whereas those called **Infinite Cycles** are remade presets from my all-time favourite album, *Infinite Cycles* by Ekhozone — these are simply beautiful and I highly recommend the album:
https://meanseed.bandcamp.com/album/infinite-cycles

🎥 How my recreated sounds sound: https://youtu.be/ktfmchBTKq0

## Contents

| File(s) | Description |
|---------|-------------|
| `Aquanode Presets 1–4.syx` | My own DX7 patches. |
| `Aquanode Aquazone Dexed Presets.syx` | My own patches used in my track "Aqua Zone". |
| `Infinite Cycles Remakes 1–6.syx` | Preset remakes from Ekhozone's *Infinite Cycles*. |
| `Infinite Cycles Remakes Greatest.syx` | Best-of selection of the remakes. |
| `midi/` | MIDI files you can play with the respective remake presets to hear what they sound like — they might not be too close to the originals though! |
| `FL Studio Infinite Cycles Remakes.flp` | FL Studio project with some presets and their MIDI files pre-arranged. Requires dexed version 0.9.8. |

## How to Load

The `.syx` files can be imported into the free [dexed](https://asb2m10.github.io/dexed/) VST, or loaded in, for example:

- FL Studio's Sytrus (top-right dropdown menu → Yamaha DX7 → Open SYSEX File)
- Native Instruments FM8
- Plogue OPS7
- a real DX7 if you have one!

Have fun with the presets! — Aquanode
