# LinPlug Alpha 3 Presets

63 presets (`.fxp`) for the **LinPlug Alpha 3** plugin — deep, bassy, aquatic sounds across basses, subs, pads, atmospheres, and FX (see the file name prefixes: `Base`, `Sub`, `Fluid`, `Light`, `Gritty`, `Reverb`, `Push`, `OpenFields`, `Inner-Vations`, …).

## About the Synth

LinPlug was a unique VST developer, but the company unfortunately shut down. LinPlug Alpha 3 had a paid and a free version; the free version still exists on some plugin archives on the internet — **my presets are for this free version**. There is also a computer magazine version floating around, also free, with more functions.

It was one of the first synth VSTs I used with which I was able to make really interesting, deep bassy sounds that I fail to recreate with other synths. It is somewhat of a wavetable synth, but with analog-inspired filters that sound really lush, especially with the chorus function added. I highly recommend it — the depth filter in particular produces interesting results.

The main atmosphere of my first long song, "Aqua Zone", was made with it, and it is used in the background of many of my tracks. I hope to hear sounds like these more often — they sound somewhat aquatic, which I really like, as you might have guessed from my channel name and genre.

Have fun with the presets and thank you for checking them out as well as my channel! — Aquanode, 2024
