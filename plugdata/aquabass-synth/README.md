Aquabasssynth is a very simple experiment of a 2-operator FM bass
line synthesizer. I made it because I was trying to learn how
you can generate VSTs using the plugdata plugin. You can view this
project as a template for making GUI-less VST code with plugdata.
The VST works and I also created a simple GUI for it when you open
it in FL Studio, it opens FL Studio's Patcher environment. :)
