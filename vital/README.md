# Aquanode Soundscapes — Vital Preset Pack

A preset pack for the [Vital](https://vital.audio) VST synthesizer. Instead of providing a single `.vitalbank` file, each preset is saved individually, so you can decide more freely which presets you want to use or keep.

The folder structure inside `Aquanode Soundscapes/` mirrors Vital's expected layout, so you can copy it into your Vital documents folder as-is.

## Contents

| Category | Description |
|----------|-------------|
| Ecophony | Nature soundscapes: Biophony (crickets, cicadas, frogs, birds) and Geophony (wind, rain, thunder, rivers, the beach). |
| Music Genre – Ambient | Bells, bubbles, flutes, organic sines, pads, and laboratory atmospheres. |
| Music Genre – DnB | Basses (Reese, sine, rollers), kicks, and atmospheric pads. |
| Music Genre – Dub Techno | Stabs, chords, pads, kicks, and noise textures. |
| Music Genre – Psychill | 303s, squelches, acid lines, alpha basses, bells, and leads. |
| Presets – FM Patches | FM synthesis sounds: bells, brass, sax, log drum, sweeps. |
| Presets – FX Patches | Sound effects: blips, alarms, metallic hits, bubbles, UI sounds, foley, sweeps. |
| Presets – Pads | Pads and soundscapes: glassy, underwater, cosmic, dubby. |
| Remakes | Recreations of sounds from songs I like — Ekhozone, Solar Fields, Carbon Based Lifeforms, Roy Mattson, PFM, Phaeleh, cv313, Warmth, Subset, and more. |
| Remakes Midi Files | A few notes or chords for the remake presets, so you can hear them in context. |

The presets are categorized as best as possible by the music genres I think they fit in (or which I initially created them for). Some presets don't really fit a single genre, so they're categorized by purpose (sound effect, pad) or by synthesis type (FM). In many cases I also have song recreation videos on my youtube channel [aquanodemusic](https://www.youtube.com/@aquanodemusic) showing the remake presets.

## How to Install (Windows)

If you want Vital to recognize the presets in its menu automatically:

1. Go to `C:\Users\<Your Username>\Documents\Vital`.
2. Copy the `Aquanode Soundscapes` folder there as-is (or make a new folder, e.g. "Aquanode Presets", containing a `Presets` subfolder with the `.vital` files).
3. The final path should look like: `Documents\Vital\<Folder Title>\Presets\<Subfolders>\<preset>.vital`.

Alternatively, double-click any `.vital` file and Vital opens automatically in standalone mode. Inside a DAW, open Vital, press the three bars at the top middle, and select **Open External Preset**.
